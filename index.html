ZenmooN SunDo Backup

Svenska

ZenmooN SunDo Backup är ett privat verktyg för en enda familj. Det kopierar familjens egna appdata (apparna ZenmooN och SunDo) i krypterad form till familjens eget Google Drive, varje natt, som skydd mot dataförlust.

Verktyget använder Google Drive med behörigheten drive.file. Den ger tillgång bara till de filer och mappar som verktyget själv skapar. Verktyget kan inte läsa övriga filer i Drive.

Verktyget har inga andra användare, erbjuds inte till allmänheten och delar ingenting med någon. Läs integritetspolicyn.

English

ZenmooN SunDo Backup is a private tool for a single family. Every night it copies the family's own app data (the ZenmooN and SunDo apps), encrypted, to the family's own Google Drive as protection against data loss.

The tool uses Google Drive with the drive.file scope. That scope gives access only to files and folders the tool itself creates. The tool cannot read any other file in Drive.

The tool has no other users, is not offered to the public and shares nothing with anyone. Read the privacy policy.
