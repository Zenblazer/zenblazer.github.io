Integritetspolicy

Senast ändrad: 2026-10-21

ZenmooN SunDo Backup är ett privat verktyg som drivs av en privatperson för den egna familjens räkning.

Vilka uppgifter verktyget kommer åt

Verktyget ber om en enda Google-behörighet: https://www.googleapis.com/auth/drive.file. Med den kan verktyget skapa, läsa, ändra och radera bara de filer och mappar som verktyget själv har skapat i familjens Google Drive. Verktyget kan inte se eller röra några andra filer, och det läser inga e-postmeddelanden, kontakter eller kalendrar.

Vad verktyget gör med uppgifterna

Verktyget laddar upp krypterade säkerhetskopior av familjens egna appdata. Kopiorna krypteras innan de lämnar familjens server; Google lagrar bara krypterad data. Uppgifterna används enbart för säkerhetskopiering och återställning. De används inte för reklam, profilering eller något annat ändamål.

Delning och lagring

Verktyget har inga andra användare än familjen. Inga uppgifter säljs, lämnas ut eller delas med någon tredje part. Den inloggningsnyckel (token) som Google ger verktyget lagras bara i familjens eget lösenordsvalv, i familjens egen hemlighetshantering och på familjens egna servrar. Ingen kopia lagras hos tjänstens ägare utöver det som ligger i familjens eget Google Drive.

Google API Services User Data Policy

Verktygets användning av information från Googles API:er följer Google API Services User Data Policy, inklusive kraven på begränsad användning (Limited Use).

Radera eller återkalla

Du kan när som helst återkalla verktygets åtkomst på myaccount.google.com/permissions och radera mappen med säkerhetskopior i Google Drive. Verktyget slutar då fungera mot det kontot.

Privacy policy

Last updated: 2026-10-21

ZenmooN SunDo Backup is a private tool run by an individual for the individual's own family.

What data the tool can access

The tool requests a single Google permission: https://www.googleapis.com/auth/drive.file. It lets the tool create, read, modify and delete only the files and folders that the tool itself has created in the family's Google Drive. The tool cannot see or touch any other file, and it does not read email, contacts or calendars.

What the tool does with the data

The tool uploads encrypted backups of the family's own app data. The copies are encrypted before they leave the family's server; Google stores only encrypted data. The data is used only for backup and restore. It is not used for advertising, profiling or any other purpose.

Sharing and storage

The tool has no users other than the family. No data is sold, disclosed or shared with any third party. The sign-in token that Google gives the tool is stored only in the family's own password vault, in the family's own secrets manager and on the family's own servers. The tool's owner keeps no copy beyond what sits in the family's own Google Drive.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Delete or revoke

You can revoke the tool's access at any time at myaccount.google.com/permissions and delete the backup folder in Google Drive. The tool then stops working against that account.
